# CLI based Backend for Ticket Booking  

A command-line interface (CLI) backend application designed to handle ticket booking operations while practicing core software engineering concepts in Java.

## Learning Objectives & Technologies
* **Build Automation:** Managing dependencies and builds using **Gradle**.
* **Data Management:** Working with the **Java Collections Framework** (`List`, `ArrayList`).
* **Functional Programming:** Utilizing the **Java Streams API** (`.stream()`, `.filter()`) for data querying.
* **Architecture:** Organizing clean code architecture using strict **Java Packages** and access modifiers.
* **File Operations & Persistence:** Creating and reading a **local JSON database** using Jackson's `ObjectMapper`.
